# Hobby Graveyard Archaeological Survey 🪦

## Overview
Welcome to the Hobby Graveyard Archaeological Survey - a Stacks blockchain project that documents the sedimentary layers of abandoned interests and provides analytical tools for hobby lifecycle management.

## Project Description
This smart contract system documents the sedimentary layers of abandoned interests: from pottery wheel to ukulele to sourdough starter memorial services. It serves as both a humorous commentary on our tendency to abandon hobbies and a practical tool for tracking hobby-related investments.

## Smart Contracts

### 1. Enthusiasm Half-Life Calculator
**Contract:** `enthusiasm-half-life-calculator.clar`

This contract predicts how long before "I'm totally going to get really into photography" becomes "why do I own so many lenses?" It tracks enthusiasm decay patterns and provides predictions for hobby abandonment timelines.

**Key Features:**
- Track hobby enthusiasm levels over time
- Calculate decay rates based on historical data
- Predict abandonment probability
- Generate enthusiasm reports

### 2. Starter Kit Depreciation Tracker  
**Contract:** `starter-kit-depreciation-tracker.clar`

This contract values the resale potential of barely-used hobby equipment gathering dust in increasingly creative storage locations. It helps users understand the financial impact of their hobby graveyard.

**Key Features:**
- Track equipment purchase prices and dates
- Calculate depreciation based on usage patterns
- Estimate current resale values
- Monitor storage location creativity index

## Getting Started

### Prerequisites
- Clarinet CLI installed
- Node.js and npm
- Git

### Installation
1. Clone the repository
```bash
git clone https://github.com/mohadmubarak770-byte/Hobby-Graveyard-Archaeological-Survey.git
cd Hobby-Graveyard-Archaeological-Survey
```

2. Install dependencies
```bash
npm install
```

3. Run tests
```bash
clarinet test
```

4. Check contracts
```bash
clarinet check
```

## Usage

### Enthusiasm Half-Life Calculator
- Register a new hobby with initial enthusiasm level
- Track enthusiasm changes over time
- Get predictions on abandonment probability
- View historical enthusiasm data

### Starter Kit Depreciation Tracker
- Add equipment purchases to your inventory
- Update usage frequency
- Track depreciation over time
- Get resale value estimates

## Contract Architecture

Both contracts follow a simple, clean architecture without cross-contract calls or complex trait implementations. They focus on:
- Data storage and retrieval
- Simple mathematical calculations
- User-friendly interfaces
- Gas-efficient operations
